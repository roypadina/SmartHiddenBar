# SmartHiddenBar

macOS 27 menu bar app: hides every status item left of its own icon via MenuBarAgent's private allow-list (left click toggles; double click / ⌥-click / hotkey open the icon bar with everything currently off the bar, under our icon), lists every app's item via the Accessibility API (`AXExtrasMenuBar`) and mirrors their menus (right-click → Apps ▸; menu = Show/Hide · Apps ▸ · Settings… · Quit), optional icon bar (⌥-click / its shortcut). Five global shortcuts recorded in Settings (`Shortcuts.swift` `shortcutActions`, Carbon hot keys): show/hide items, icon bar (default ⌃⌥B; the old `hotkey` preset migrates once), list apps, settings, quit — all others default off. Stored as `toggleShortcut` / `barShortcut` / `appsShortcut` / `settingsShortcut` / `quitShortcut` = `"keyCode:carbonMods"`, `""` = off. ⌃⌥M clashes with Wispr Flow. Swift sources in the repo root (`*.swift`), built by `./build.sh` (icon set chosen by `SET=` at its top, assets in `Assets/icons/`, regenerated by `Assets/icons/gen.py`).

## Rules
- **Always run the `/Applications/SmartHiddenBar.app` copy, never `build/`.** On macOS 27, MenuBarAgent resolves allow-listed bundle ids through LaunchServices, which picks the `/Applications` copy; a copy running from `build/` never matches, so the allow-list hides its own icon wherever it sits. `build.sh` installs to `/Applications` unless that copy is running — quit it first, then rebuild.
- Launching/relaunching SmartHiddenBar from a session is OK (Roy, 2026-10-02) — `open /Applications/SmartHiddenBar.app` (it inherits the session env even with `env -u`; harmless — the app spawns no children); quit with `osascript -e 'quit app "SmartHiddenBar"'`. Never drive his UI otherwise (no pressing, clicking or key events).
- Signing: `build.sh` uses the local "KeyLayoutSwitcher Dev" identity so the Accessibility grant survives rebuilds. Ad-hoc signing changes the cdhash every build and re-prompts. Reset a broken grant with `tccutil reset Accessibility com.roypadina.SmartHiddenBar` (Screen Recording: `tccutil reset ScreenCapture com.roypadina.SmartHiddenBar`).
- Log: `~/Library/Logs/SmartHiddenBar.log`. Defaults domain `com.roypadina.SmartHiddenBar`.
- Git: private repo `roypadina/SmartHiddenBar`, remote via SSH alias `github-padina`. Commit email is the repo-level noreply address (gmail is rejected by GitHub email privacy). Commit + push after each working fix.
- `probe/` (gitignored) holds two trivial status-item apps for isolating menu bar issues.
- In zsh, `log` is a builtin: use `/usr/bin/log stream ...`.
